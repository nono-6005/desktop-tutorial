# sheet-clip（URL・文言をスプレッドシートに追加）

Galaxy S25 で URL や文言を共有すると、Googleスプレッドシートに1行追加されます。
同じURLは重複として追加されません。

## 構成

```
[共有シート / 自動化アプリ]  →  HTTP POST (JSON)  →  [Apps Script ウェブアプリ]  →  [スプレッドシート clips シート]
```

- `apps-script/Code.gs`：受け取り・重複判定・追記を行うコード（このフォルダ内）
- 送信側：Android の HTTP 系自動化アプリ（HTTP Shortcuts など）

## 1. スプレッドシートの準備

1. 書き込み先のスプレッドシートを開く（どれを使うかは下の「未決事項」を参照）
2. シート名を `clips` にする（無ければ作成）
3. 1行目にヘッダーを入れる：

   | A | B | C | D | E | F |
   |---|---|---|---|---|---|
   | 日時 | URL | タイトル | テキスト | メモ | 端末 |

## 2. Apps Script の設定

1. スプレッドシートの「拡張機能」→「Apps Script」を開く
2. `apps-script/Code.gs` の内容を貼り付けて保存
3. 「プロジェクトの設定」→「スクリプトプロパティ」に次を追加する
   - キー：`TOKEN`
   - 値：推測されにくいランダムな文字列（リポジトリには書かない）
4. 「デプロイ」→「新しいデプロイ」→ 種類「ウェブアプリ」
   - 次のユーザーとして実行：自分
   - アクセスできるユーザー：全員
5. 表示された URL（`https://script.google.com/macros/s/.../exec`）を控える

コードを変更したら「デプロイを管理」から新バージョンを発行する必要があります。

## 3. 送信側（HTTP Shortcuts など）の設定

HTTP リクエストの内容は次のとおりです。

- メソッド：`POST`
- URL：上で控えた `/exec` の URL
- ヘッダー：`Content-Type: application/json`
- 本文（JSON）：

  ```json
  {"token":"（TOKEN と同じ値）","url":"{共有されたURL}","title":"{共有されたタイトル}","text":"{共有された文字}","device":"S25"}
  ```

- 共有シートの受け取りで、`{...}` の部分に共有内容を入れる
- **リダイレクトに従う** を有効にする（Apps Script は POST 後にリダイレクトを返すため、無効だと失敗します）

## 4. 応答の見方

```json
{"ok":true,"duplicate":false}   → 追加された
{"ok":true,"duplicate":true}    → 既に登録済み（追加されない）
{"ok":false,"error":"unauthorized"} → TOKEN が一致しない
```

## 重複判定のルール

- URL は次の形に正規化して比較します。`#` 以降を削除、`utm_*`・`fbclid`・`si` を削除、末尾の `/` を削除
- URL が空の共有（文字だけ）は重複判定せず、そのまま追加します
